Rampino – ramp dataset

The ramp data used in the Rampino app is a derived database of OpenStreetMap leisure=slipway objects in Germany, Austria, the Netherlands and Sweden (release 2026.11).

rampino-ramps-2026.11.geojson (GeoJSON, about 0.7 MB)

© OpenStreetMap contributors. This dataset is made available under the Open Database License (ODbL) 1.0. See openstreetmap.org/copyright.

Fields: i id (country + OSM type + OSM id), n name, p nearest named place (from OSM), s surface, f fee (1/0), x access, w width (m), g slope (%), h opening hours, l lit, op operator, cr crane, k canoe-only. Only values present in OSM are included; nothing is estimated. Private, disused and FIXME-tagged objects are left out.
